# 市场调研工作流 · Market Research Workflow

一套从「产品点子」到「市场调研报告」的完整工作流，打包为 AI 助手可直接执行的方法包（支持 WorkBuddy，同时兼容 Claude Code）。

它不是一个问卷模板，而是一套**可执行的调研流程**：AI 负责检索、建表、分析、组装，人负责关键决策与数据核验，最终产出数据驱动的调研报告与商品数据表。

## 六步流程

```
需求澄清 → 关键词地图 → 商品数据表 → 六板块调研 → 报告组装 → 导出交付
```

**六板块**：政策 / 空间与发展 / 市场规模 / 竞品 / 定价 / 技术与外观专利

**三个人工关卡**：调研简报确认（Step 0 后）、关键词词表确认（Step 1 后）、数据补表（商品数据表建好后）

## 五个贯穿性原则

1. **数据溯源强制**：每个数据点带 来源 + 日期 + 置信度分级（★★★ 官方/多源一致、★★ 单一来源、★ 估算）
2. **找不到就写「未获取」**：禁止用合理推测填充；估算必须标注假设
3. **数据优先**：能用表格说清的不写段落；每节先表后文
4. **中间产物落盘**：关键词地图、来源清单、商品数据表全部保留，供复查与增量更新
5. **取数合规**：只采公开数据；只用本人实名账号；遇风控降频、不绕过；数据仅用于调研分析

## 快速开始

**方式一：拷贝文件夹**

把 `market-research/` 复制到 AI 助手的技能目录：

- WorkBuddy（Windows）：`%APPDATA%\WorkBuddy\skills\`
- Claude Code：`~/.claude/skills/`（或项目的 `.claude/skills/`）

**方式二：导入 zip**

WorkBuddy 的 Skills 管理中选择「导入 Skills」，用 `market-research-skill.zip`。

**方式三：从 Git 仓库导入**

WorkBuddy 的 Skills 管理中选择「从仓库导入」，填入本仓库地址。

安装后直接对话触发，例如："帮我调研一下 XX 品类，我想做个 XX 产品"。完整使用说明见 [`使用说明.md`](使用说明.md)。

## 样板：用这套流程产出的报告

[`market-research/assets/报告样板-顶天立地架.md`](market-research/assets/报告样板-顶天立地架.md) 是一份用本工作流从零完成的完整市场调研报告实例（约 4.3 万字）——涵盖六板块展开、专利分析、结论修正与置信度声明，可直观感受这套流程的产出形态。

## 电商取数扩展（可选）

默认流程中商品数据依靠人工采集（把商品页信息粘贴给 AI 整理）。若调研频率较高，可安装 [`电商取数扩展（可选）/`](电商取数扩展（可选）/说明.md) 中的开源工具，让 AI 直接检索淘宝 / 京东 / 小红书等平台，商品数据表自动填充——装好后工作流会自动优先使用工具取数，取不到的字段仍提示人工补充。

## 脚本

`market-research/scripts/` 下有三个辅助脚本（均为可选项）：

| 脚本 | 用途 | 依赖 |
|---|---|---|
| `preflight.py` | 报告导出 PDF 前的排版检查 | 无（纯标准库） |
| `table_check.py` | 商品数据表交付前检查（BOM/列数/待核验行） | 无（纯标准库） |
| `md2pdf.py` | Markdown 转中文排版 PDF（浏览器无头渲染） | Python + `markdown` 库 + Edge/Chrome |

没有 Python 环境也不影响使用——检查清单可以直接让 AI 逐条核对，PDF 可用 AI 助手自带的文档导出能力生成。
