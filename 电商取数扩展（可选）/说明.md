# 电商取数扩展（可选）：让 AI 直接搜淘宝 / 京东 / 小红书

这份扩展是《市场调研工作流》的**可选升级**。装好之后，调研走到"商品数据表"环节时，AI 可以直接调用工具去平台取数（价格、付款人数、店铺、规格、口碑笔记），不再需要你逐个商品页人工抄录。

**装不装？一个简单的判断标准**：

- 偶尔做一次调研（几个月一次）→ **不用装**，人工模式够用
- 高频调研、或每次要采几十个 SKU → 值得装，能省掉大量复制粘贴

## 工具一览

| 工具 | 覆盖平台 | 形态 | 说明 |
|---|---|---|---|
| **cn-scraper-mcp** | 淘宝/天猫、京东、小红书、知乎、微博、B站等 | Python 包 | 推荐**先装这一个**，覆盖大部分取数需求 |
| xiaohongshu-mcp | 小红书（笔记 + 评论专线） | 绿色软件（两个 exe） | 需要时再装；cn-scraper 已含小红书基础取数，这个是增强专线 |

## 一、cn-scraper-mcp 安装与配置

### 1. 前置条件

- Python 3.11 或更高版本（[python.org](https://www.python.org/downloads/) 下载安装，安装时勾选 **Add Python to PATH**）
- 本机装有 Chrome 或 Edge 浏览器（京东取数会调用）

### 2. 安装（命令行执行）

首选在线安装（用清华镜像，速度快）：

```
pip install cn-scraper-mcp -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果网络受限，也可以离线装本附件里带的安装包（`cn-scraper-mcp` 文件夹内）：

```
pip install "cn_scraper_mcp-0.5.0-py3-none-any.whl"
```

> 注：离线包只含工具本体，它的依赖组件仍需联网从 PyPI 拉取——公司/家里的正常网络都没问题。

### 3. 配置到 WorkBuddy

打开 WorkBuddy 的 MCP / 连接器配置（Windows 参考位置：`C:\Users\你的用户名\.workbuddy\mcp.json`，以设置面板里的连接器入口为准），加入：

```json
{
  "mcpServers": {
    "cn-scraper": {
      "command": "cn-scraper-mcp"
    }
  }
}
```

**如果提示找不到命令**：先在命令行运行 `where cn-scraper-mcp` 拿到完整路径，替换 `command` 的值；注意 Windows 路径里的反斜杠在 JSON 里要写成双份，例如 `"C:\\Users\\xxx\\Python312\\Scripts\\cn-scraper-mcp.exe"`。

**如果取数报浏览器相关错误**：在同一段配置里加环境变量指定浏览器，例如：

```json
{
  "mcpServers": {
    "cn-scraper": {
      "command": "cn-scraper-mcp",
      "env": {
        "CHROME_PATH": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe"
      }
    }
  }
}
```

### 4. 登录（每个平台做一次）

在 WorkBuddy 对话里说一句"帮我登录淘宝"（对应工具 `guided_login`，平台参数 `taobao`）——它会自动打开浏览器、跳到淘宝官方登录页，**你自己扫码**，登录完成后登录态自动保存。

常用平台名：`taobao`（淘宝）、`jd`（京东）、`xiaohongshu`（小红书）、`zhihu`、`weibo`、`douyin`。

登录态保存在本机用户目录 `C:\Users\你的用户名\.cn-scraper-cookies\`（京东另存独立的本地浏览器 Profile）——**只在你本机，永远不会随文件分享出去**；工具本身也不读取、不保存你的账号密码。

### 5. 验证

对话里说："用淘宝搜索『保温杯』，看看能取到什么数据"。能返回商品名、价格、店铺即为成功。

## 二、xiaohongshu-mcp（小红书专线，可选）

### 1. 启动服务

进入 `xiaohongshu-mcp` 文件夹：

1. 双击运行 `xiaohongshu-login.exe` → 弹出浏览器，扫码登录小红书（只需首次）
2. 双击运行 `xiaohongshu-mcp.exe` → 服务启动（黑色窗口**保持打开**，这是常驻服务）
3. 服务地址：`http://localhost:18060/mcp`

### 2. 配置到 WorkBuddy

在 MCP / 连接器配置里加入：

```json
{
  "mcpServers": {
    "xiaohongshu": {
      "type": "http",
      "url": "http://localhost:18060/mcp"
    }
  }
}
```

### 3. 注意事项

- **杀毒误报**：Windows 安全中心可能对该程序报毒（Go 编译程序的常见误报），按文件夹里 `windows_guide.md` 的图示添加排除项即可
- **登录互踢**：同一个小红书账号不要在其他网页/App 端重复登录，会互相挤掉登录态
- 每次开机用之前，先启动 `xiaohongshu-mcp.exe`（把这个窗口放着别关）

## 三、装好之后怎么用

不需要改变任何习惯——照常说"帮我调研 XX 品类"。工作流走到商品数据表环节时会自动优先用这些工具取数（淘宝的付款人数、京东的精确价格与规格、小红书的口碑笔记），取不到的字段仍标"待核验"交给你人工补。

**一句话提醒**：工具返回的销量数字仍然要带口径（"X+人付款"是人数模糊值、京东前台显示的是评价数），这条规范在工作流里已内置，不要让 AI 把不同口径的数字直接比较。

## 四、常见坑速查

| 症状 | 处理 |
|---|---|
| cn-scraper 取数报 "An unexpected error occurred" | 多半是登录态过期 → 重新 guided_login 对应平台 |
| 淘宝报 RGV587 /「被挤爆」 | 登录态失效 → 重登；并降低使用频率 |
| 京东取数失败 | 确认本机有 Chrome 且已 guided_login("jd") |
| 小红书服务连不上 | 先启动 xiaohongshu-mcp.exe；检查 18060 端口未被占用 |
| 小红书登录态失效 | 重新运行 xiaohongshu-login.exe |
| 被平台限流/风控 | 停一停再继续，不要高频连续请求 |

## 五、合规底线（务必遵守）

这些工具是"用你自己的账号，看你本来就能看到的内容"，请守住以下红线：

- 只采公开数据；只用本人实名账号
- 遇风控限流就降频等待，不绕过验证码、不绕过风控
- 采集内容仅用于本次调研分析，不转售、不做批量抓取
- 工具作者亦声明：仅用于学习和研究目的，批量抓取可能违反平台服务条款
